# Engineering Dashboard v3
Professional iPhone app concept for Civil Engineer / Site Engineer.
- SwiftUI, iOS 17+
- Arabic RTL
- Local demo data
- Dashboard, Projects, Daily Logs, BOQ, QC/NCR, Reports, Profile
- Prepared as a clean starter for cloud build/signing

Open `EngineeringDashboard.xcodeproj` in Xcode on a Mac, or use a compatible cloud macOS build service.
